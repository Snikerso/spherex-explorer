Rehearse the actual narration: include the solo author/team name in the title card and measure the rendered duration. Use cuts between real interactions; do not imply that archive downloads happen instantly. Prefer preloaded real data, clearly labelled as cached where applicable. If the model is unavailable, record manual control and change the narration accordingly.

Persistent small caption for comparison scenes: **Visual exploration · wavelengths may differ · no confirmed detection**. RGB scenes should say **False-color composite**. Do not use the WISE 0855 field as proof that WISE 0855 itself is visible.

Record at a resolution where source dates and control labels remain readable. Keep the final file below 30 seconds including title and end cards. English voiceover avoids a separate translation step; any non-English speech needs English subtitles. Use SI media labels if applicable. Do not include likenesses or voices of people under 18.

## Alternative: seven-slide content outline

This is an outline to build into an actual deck; do not submit this Markdown file as a completed presentation.

1. **SPHEREx Explorer** — “Explore infrared skies across time.” Add team name and solo author name, and challenge name. Use an actual application screenshot.
2. **The problem** — Archive observations differ in time, wavelength, orientation, and coverage. Make these differences visible before interpreting change.
3. **The journey** — Enter coordinates → select real observations → align → blink or compare. Show the working search and image view.
4. **A copilot with shared controls** — A real command changes a setting; the user adjusts it manually. Show the resulting controls.
5. **Built on NASA data** — SPHEREx Level 2 / IRSA → FITS + WCS → shared sky grid. Include the final demo's release, observation IDs/dates, and source links.
6. **Explore responsibly** — RGB, stacks, point samples, and epoch comparisons. False colors; possible wavelength effects; no PSF matching or confirmed discovery.
7. **Try it and continue** — Public project link and team credits. Next: validated motion measurements and candidate follow-up. Add data/software credits and SI acknowledgements as applicable, without creating extra slides.
